# Terminology

Useful customer language and common transcription variants. Use these to interpret intent; do not invent facts.

## Storage intent

- saman rakhna / samaan rakhna / saman rakhna hai
- ghar ka saman / household goods / furniture store
- storage / store / storing
- godown (personal goods context)
- temporary storage / long term storage
- kitne mahine / for a few months / 3 months / 6 months

## Relocation / packers & movers

- ghar shift / ghar shift karna hai
- office shift
- shifting / relocate / relocation
- packers / movers / packers and movers
- packing / loading / unloading
- transport / transportation

## B2B / warehouse

- warehouse / ware house
- stock rakhna / inventory
- business storage / commercial storage
- godown (stock/inventory context)

## Logistics / operations

- pickup / pick up / pick-up
- delivery / drop / drop off
- vehicle / tempo / truck / driver
- aaj aana tha / kal aana tha / abhi tak koi nahi aaya (missed/delayed pickup)

## Pricing / sales

- quotation / quote / rate / price
- kitna lagega / monthly rent / charges
- discount / offer
- booking / book / confirm

## Brand / agent phrasing

- Xtended Space / Extended Space / Extended Express (common ASR mishears)
- central space (possible ASR mishear of Xtended Space)
